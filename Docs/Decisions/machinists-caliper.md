# Scadretto interaction study

Scadretto evaluates authored OpenSCAD, traces the resulting geometry back to its expressions, and writes checked patches against the original source. An instance picked in the viewport might be one of several generated by the same expression. The memorable moment is when you take hold of one hole, see the other holes answer, and change them all by rewriting a single number.

## 1. Machinist’s Caliper

**Inspiration.** A model can be exact and still feel distant when its dimensions live in an inspector. The existing handles already know the selected value, the motion it permits, and the geometry that shares it. Put the measurement at the point where the hand is working.

**Before.** Pick the third bore in the mounting plate. Its editable grip appears, the affected bores are outlined, and the inspector names the controlling expression and its scope. The viewport stays clear until you grab the grip.

**During.** Two jaws sit on the projected grip axis. An amber jaw stays at the starting position and a mint jaw follows the candidate value. A dark engraved plate keeps the measurement beside the cursor and displays the property and the old and proposed values in monospaced digits. Its leader stays attached if the plate has to shift to fit the viewport edge. The current guides move through every affected cutter, even when the projected difference at the selected bore is only a few points. With snap enabled, entering a new valid detent requests an alignment pulse from macOS.

**After.** A successful source write stamps the plate “Source updated” for 750 ms. The mesh can finish evaluating in its own time. Escape lifts the instrument away and keeps the original source. Undo reverses the accepted drag in one operation.

**Show someone.** Pull one bore from 4 to 5. Four wire rings respond and the measurement records the exact change on the part. The inspector and keyboard entry are available for precise values, and the caliper uses the same constraints and snap values as the existing drag.

## 2. Shared-Source Constellation

**Inspiration.** In procedural CAD, the pixel you touch often belongs to a family. The important discovery is which other objects follow from the same authored expression.

**Before.** Pick a cutter. A small socket appears on the selected surface and a matching socket appears beside its controlling token. Hold Option over either socket to unfold the dependency view. Each reachable on-screen instance gets a point. Offscreen instances are counted at the edge closest to their projected position.

**During.** Moving across the points previews their instances one at a time. Grabbing the original handle freezes the membership and makes short rays leave the controlling token and follow the moving guides. Draw at most twelve rays, prioritizing nearby and visible instances, then print the total next to the token. A translated copy and a subtractive cutter use distinct endpoints so that the user can tell how the edit propagates.

**After.** Release to write the same single transaction. The sockets remain available so a user can alternate between inspecting the expression and reviewing shapes. Releasing Option folds the dependency view away. Escape during drag returns the old guides and leaves both the code and membership intact.

**Show someone.** Touch the hole in one corner and watch the recipe briefly reveal every place it was used. The extra connections are on demand. A plain click remains selection, and text users can follow the same relationship with Reveal Selected Source.

## 3. The Comparison Cut

**Inspiration.** Evaluating OpenSCAD is a transformation with an uncertain duration. The instant the old mesh becomes the newly generated part deserves a clear reveal, especially when a change is subtle.

**Before.** Pick a property and drag as usual. The current surface remains under the manipulable guides. On release, retain the last confirmed geometry while the worker evaluates the checked source revision.

**During.** When the next mesh is confirmed, reveal it through a single movable plane in screen space. The old and new geometries keep the same camera and lighting. The plane begins at the selected feature, so a one-millimeter change is visible immediately. Roll the plane across the part with a horizontal mouse gesture or the arrow keys while Compare has focus. Mark each side with its value, and leave a clear badge while a comparison is pinned.

**After.** Release the temporary compare gesture and the current mesh fills the viewport again. A pinned comparison can be dismissed with Escape. If evaluation fails, show the stale result and the diagnostic, and leave Undo available. With Reduce Motion, show a stationary divider and switch meshes without a sweep.

**Show someone.** Slide the divider through a plate and see each larger opening cut through exactly where the smaller one used to be. Ordinary edits settle directly to the new mesh. The comparator appears when invoked and uses only one previous mesh to keep memory predictable.

## Commitment

**Machinist’s Caliper** makes Scadretto’s distinctive combination of tactile control, precise values, and shared authored geometry legible in a single gesture. It improves the moment when a user decides how far to move. It works with the existing real-time guides while the worker is busy and gives the source write its own brief acknowledgment. The mounting plate demonstrates the idea in ten seconds with a bore drag, a visible change to four rings, and a single Undo.

## Deliberate boundaries

The prototype leaves workspace organization, source, camera controls, and the worker pipeline intact. It avoids audio so repeated drags stay quiet, and uses the hardware’s alignment feedback only when snapping is enabled. The caliper carries no persistent measurement objects, physics, simulated machining particles, or new gestures. It appears immediately, follows the input directly, and disappears without an animated transition. The receipt confirms the source edit, while the existing preview status reports evaluation.
